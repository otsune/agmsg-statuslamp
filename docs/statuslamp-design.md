# Statuslamp: JSON による状態表示

## 目的

agmsg Desktop の選択中チームについて、各エージェントの名前と大きな ASCII アートのパトランプを表示する。既存の idle、working、blocked、unknown と色を引き継ぐ。状態は Desktop の端末出力に基づく推定である。

## 接続

Desktop が専用フォルダーに `panestatus.json` を出力する。アドオンは `files:read` を宣言し、ユーザーがそのフォルダーへのアクセスを許可した後、ファイルを定期的に読み取る。Desktop の設定、データ、ログなどの保護領域はアドオンが読めないため、出力先はそれらの外に設ける。端末出力やメッセージ本文は出力しない。

出力内容の案:

```json
{
  "version": 1,
  "team": "example",
  "updated_at": "2026-11-09T00:00:00Z",
  "members": [
    { "name": "alice", "state": "working" },
    { "name": "bob", "state": null }
  ]
}
```

`state` は `idle`、`working`、`blocked`、`unknown`、または Desktop が対応する端末を観測できない場合の `null` とする。unknown と未取得を分ける。プロセス ID、端末テキスト、メッセージは含めない。

## 更新と表示

- Desktop は初期状態、状態変更、端末終了、メンバーやチームの変更を反映する。稼働中も更新時刻を更新する。
- 読み取り中に部分的な JSON が見えないよう、同一フォルダーの一時ファイルを経由して置換する。異なる OS で置換が成功することを確認する。
- アドオンは状態値を検証し、不正・未対応のファイル、アクセス拒否、ファイル不在、更新停止を画面で区別する。古い値を現在の状態として表示しない。
- 選択されたチーム名を表示し、状態以外も文字で判別できるようにする。idle と unknown は現行の緑、working はオレンジ、blocked は赤。未取得はグレーとする。
- アドオンを閉じても端末は終了しない。

## 実装と確認

1. Desktop 側でファイルの出力先、更新、終了時の扱いを実装する。元の paneStatus と既存のメンバー対応を再利用する。
2. `fujibee/agmsg-addon-sample` をテンプレートにアドオンを作り、`files:read` でファイルを読む。
3. 実際の Desktop とアドオンを使い、アクセス許可、状態変化、未起動、チーム切替、端末終了、再起動、ファイル欠落・不正・更新停止を確認する。Windows で置換を確認し、結果を残す。

## 未決事項

- ポーリング間隔と、更新停止と判定する時間。
- アプリの異常終了時や複数 Desktop 起動時のファイルの所有関係。
